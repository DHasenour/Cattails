# Cattails
Cattails is an ongoing project in the space of nuclear hydrodynamics codes. It is built off the moving mesh code RT1D and the testbed code in Hasenour and Duffell 2025. The primary equation of state is Helmeos, see cococubed.com (Frank Timmes research page). The reaction networks are generated by pynucastro (see pynucastro.github.io/pynucastro/).

At the moment, Cattails is a 1D spherical symmetric, self-gravitating, moving mesh, nuclear hydrodynamics code.
